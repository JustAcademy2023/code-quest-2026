# Syntax Lab 2026

An interactive, dark mode landing page about the **top programming languages to learn for IT jobs in 2026**. Flip through an IDE style code lab, compare Python, JavaScript, Java, C and C++, SQL and R, follow a ninety day roadmap and explore guided learning paths and reading links.

## What is inside

- Sticky glass header with navigation and a Free Demo button
- Aurora gradient background, animated hero and typing terminal line
- Interactive code lab with tabs for six languages, each with a snippet, description, "gentle start" bar and tags
- A ninety day roadmap timeline with three missions
- Four Pune learning paths: Python, JavaScript, MERN Stack and Data Analytics
- A four article reading list, demo and brochure banner, and a full footer
- Scroll reveal animations that respect reduced motion preferences

## Run it locally

No build step is required. Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch of a repository named `syntax-lab-2026`.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will go live at `https://YOUR-USERNAME.github.io/syntax-lab-2026/`.

## Tech notes

- One HTML file with embedded CSS and a small amount of vanilla JavaScript
- Responsive layout built with CSS Grid and flexbox
- Accessible tabs, ARIA labels and keyboard friendly buttons
- Fonts: Sora and JetBrains Mono from Google Fonts, with system fallbacks
